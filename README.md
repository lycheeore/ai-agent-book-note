## 几处贯穿各期的笔记习惯

- **标注来源**：书中数字 / 仓库自带结果 / 本机实跑 / 自建数据，四类严格区分；自建语料一律标注「非书中官方结果」。
- **不掩盖反例**：与仓库 README 旧结果不一致、或与正文预期相反的实测（例如「加重排反而掉分」），照原样写进笔记。
- **机制写到可验证**：现象之外给出源码位置与定点诊断，例如「融合权重为 0 ≠ 关闭通道」是读 `fusion.py` + 手工调用 `fuse()` 交叉验证得到的。
- **一图一节**：每个小节配一张来自真实产物的截图，不复述原文。
