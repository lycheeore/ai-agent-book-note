## 打卡要求：重新理解 RAG 与记忆

**一句话**：Context 是唯一的出口，Memory 和 RAG 都是入口；而本章补上了关键的一半——**入口的质量，在索引期就已经被决定**。

**① RAG 不是「检索 + 生成」两步，而是一条五阶段流水线，各阶段职责不可互相代偿。**

分块 → 稠密/稀疏检索 → 融合 → 重排序 → 生成。本期实测：BM25 与 Dense 的失分点**几乎不重合**（BM25 在语义改写与中文跨语言上翻车，Dense 在近似编码上翻车），**RRF 融合把两者一起救回满分**；但重排序**只对已进入候选池的文档生效**——所以「该改召回还是改排序」，必须先拆到阶段指标才能判断。

**② Memory 与 RAG 是同一套技术的两个尺度，而且这正是本章的实现路径。**

论证结构是「先在知识库尺度上把检索技术做成熟（3-4~3-10），再反过来应用到用户记忆（3-9、3-11）」。所以「Memory 是用户尺度的 RAG」不只是比喻——**连失败模式都一样**：孤立分块会让相互矛盾的记忆并列（转账三方修改用例），解法也一样（给分块补上下文前缀）。

**③ 记忆的终点不是「存下来」，而是「能在对的时刻被主动想起」。**

三层次评估框架（基础回忆 / 多会话检索 / 主动服务）里，第三层最难，因为它要求**全局概览与精确细节两种视角同时在场**：Advanced JSON Cards 常驻（少量关键事实）+「上下文感知检索」按需召回（海量原始对话）。只靠常驻会丢细节，只靠检索发现不了跨会话的隐藏关联。

## 本期结论

| # | 结论 | 证据 |
| :--: | --- | --- |
| 1 | 单路检索都做不到满分（BM25 MRR 0.7917 / Dense 0.9167），失分点不重合；**Hybrid-RRF 三项全 1.0000** | [逐阶段指标](实验记录/images/exp-01-stage-metrics.png) |
| 2 | **阶段叠加不是单调增益**：RRF 加挂重排后 MRR 从 1.0000 掉到 0.9583（HTTP-400 从 1.00 → 0.50） | [重排反降](实验记录/images/exp-05-rerank-regress.png) |
| 3 | **同义词缺口在候选集层面**：查 `kitty` 时 BM25 返回空集，Dense 正常召回——调参造不出候选集里没有的文档 | [缺口闭合](实验记录/images/exp-03-synonym-gap.png) |
| 4 | **权重为 0 ≠ 关闭通道**：零分文档仍占候选位，靠稳定排序「隐形保留」；要关一路必须禁用阶段 | [融合参数](实验记录/images/exp-04-fusion-params.png) |
| 5 | 融合增益在候选池最小时最大：top_k=1 时两路都不满分，**RRF 仍 1.0000** | [融合参数](实验记录/images/exp-04-fusion-params.png) |
| 6 | 同一段对话跑四种记忆格式：`notes` 与 `enhanced_notes` **产物结构完全相同**（差异在提示词）；`advanced_json_cards` 出现 backstory/person/relationship，并**编造了一个不存在的日期** | [四种格式](实验记录/images/exp-06-memory-modes.png) |

## 知识脉络

```
第 1 章  Agent = LLM + 上下文 + 工具
              ↓ 把「上下文」拆开，做成一门工程
第 2 章  这一次任务里，模型该看到什么
         └─ 静态前缀受 KV Cache 约束；轨迹膨胀靠压缩与隔离
         └─「上下文感知压缩」= 运行期对对话历史做减法
              ↓ 把「一次任务」放大到「跨任务」
第 3 章  跨会话之后，还该记住什么、查什么          ← 本期
         ├─ 两个尺度：用户记忆（懂你）/ 共享知识库（领域专家）
         ├─ 五阶段流水线：分块 → 稀疏+稠密 → 融合 → 重排 → 生成
         ├─ 索引期决定质量上限：「上下文感知检索」= 索引期对文本块做加法
         └─ 收口：双层记忆架构（结构化概览常驻 + 感知检索按需）
              ↓ 检索内容只能影响措辞，有副作用的动作必须独立授权
第 4 章  执行工具（下一期）
```

本章小结给了一个很准的定位：**本章建的是第一章发现循环中的「提案」段**——把一条证据变成一次最小、可审查、可回滚的修改，但不负责判断系统整体是否变好。
